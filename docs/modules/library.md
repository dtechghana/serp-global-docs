# Library Management

The library module provides a basic cataloguing and book-circulation system — tracking the school's book stock, recording issues to students and staff, and monitoring returns and overdue items.

---

## Book Categories

Organise your catalogue into categories before adding books (e.g. Mathematics, Science, Fiction, Reference).

1. Go to **Library → Categories**
2. Click **Add Category**
3. Enter the category name and click **Save**

Categories can be renamed or merged at any time.

---

## Adding Books

1. Go to **Library → Books**
2. Click **Add Book**
3. Fill in:
    - **Title**
    - **Author**
    - **Category**
    - **ISBN** (optional)
    - **Copies** — total number of copies held
    - **Year of publication** (optional)
4. Click **Save**

sERP assigns a sequential Book ID automatically. The catalogue is searchable by title, author, or category.

---

## Issuing Books

Record a book loan to a student or staff member.

1. Go to **Library → Issue Book**
2. Search for the borrower by name or ID
3. Select the book title from the catalogue
4. Set the **Due Date**
5. Click **Issue**

The borrower's record and the book's available-copy count are updated immediately.

---

## Returning Books

1. Go to **Library → Return Book**
2. Search for the borrower or scan the Book ID
3. Select the item to return from the borrower's active loans
4. Click **Record Return**

If the book is returned after the due date, the overdue status is noted in the return record.

---

## Finding a Book

Use **Library → Find Book** to check whether a title is in the catalogue and how many copies are currently available (total copies minus copies on loan).

---

## Reports

| Report | Location |
|--------|----------|
| All books (full catalogue) | Library → Books → Export |
| Currently issued books | Library → Reports → Issued |
| Overdue items | Library → Reports → Overdue |
| Issues by date range | Library → Reports → By Period |
